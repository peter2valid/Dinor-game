# Dino Run - Android Game

An Android clone of the classic Chrome Dinosaur Game, built with Java and Android Studio.

## 📱 About

Dino Run is a side-scrolling endless runner game where you guide a pixelated Tyrannosaurus rex across a landscape, jumping over cacti to achieve the highest score possible. This Android version faithfully recreates the original Chrome browser game experience.

## 🎮 How to Play

- **Tap the screen** to make the dinosaur jump over obstacles
- The game automatically speeds up as you progress
- Avoid colliding with cacti to keep playing
- Try to beat your high score!

## 🛠️ Technical Details

### Architecture

- **GameView**: Extends `SurfaceView` for efficient rendering
- **GameThread**: Separate thread handling ~60 FPS game loop
- **Model Classes**: Clean separation of game objects (Dino, Cactus, Cloud, Earth)
- **Utilities**: Centralized configuration, resource management, and collision detection

### Key Features

- ✅ Smooth 60 FPS gameplay
- ✅ Touch-based controls
- ✅ Score tracking with high score persistence
- ✅ Dynamic difficulty progression
- ✅ Landscape orientation lock
- ✅ Collision detection with pixel-perfect hitboxes
- ✅ Game over & restart functionality

### Requirements

- **Minimum SDK**: Android 5.0 (API 21)
- **Target SDK**: Android 13 (API 33)
- **Java Version**: 1.8
- **Dependencies**: AndroidX AppCompat, Material Components

## 🚀 Building the App

### Prerequisites

1. **Android Studio** (Arctic Fox or newer)
2. **Android SDK** (API 21+)
3. **Java Development Kit (JDK)** 8 or higher

### Steps

1. **Open the project** in Android Studio:
   ```bash
   File → Open → Select the DinoRunAndroid folder
   ```

2. **Sync Gradle files**:
   - Android Studio will automatically prompt to sync
   - Or click "Sync Now" in the banner

3. **Connect a device or emulator**:
   - **Physical Device**: Enable USB debugging
   - **Emulator**: Create an AVD with API 21+

4. **Run the app**:
   - Click the green "Run" button (▶️)
   - Or use `Shift + F10`

## 📦 Building APK

### Debug APK

```bash
./gradlew assembleDebug
```

Output: `app/build/outputs/apk/debug/app-debug.apk`

### Release APK (for publishing)

1. **Create a keystore**:
   ```bash
   keytool -genkey -v -keystore dino-run-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias dino-run
   ```

2. **Configure signing** in `app/build.gradle`:
   ```gradle
   signingConfigs {
       release {
           storeFile file("path/to/dino-run-key.jks")
           storePassword "your-password"
           keyAlias "dino-run"
           keyPassword "your-password"
       }
   }
   ```

3. **Build release APK**:
   ```bash
   ./gradlew assembleRelease
   ```

## 🎨 Customization

### Adjust Game Difficulty

Edit `Constants.java`:

```java
public static final int CACTUS_SPEED = 12;           // Obstacle speed
public static final int CACTUS_SPAWN_DISTANCE = 600; // Space between cacti
```

### Change Colors

Edit `res/values/colors.xml`:

```xml
<color name="background">#F5F5F5</color>
<color name="object">#535353</color>
```

### Modify Physics

Edit `Dino.java`:

```java
private static final int GRAVITY = 2;
private static final int JUMP_VELOCITY = -35;
```

## 🐛 Debug Mode

Enable debug mode in `Constants.java` to see collision boxes:

```java
public static final boolean DEBUG_MODE = true;
```
